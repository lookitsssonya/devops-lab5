# Linux Commands

- `pwd` - текущий каталог
- `ls -la` - список файлов с деталями
- `cd` - переход по каталогам
- `mkdir -p` - вложенные каталоги
- `cp -r` - копирование каталогов
- `mv` - перемещение и переименование
- `rm -r` - удаление каталога
- `grep` - поиск по шаблону
- `find` - поиск файлов
- `chmod +x` - сделать исполняемым
